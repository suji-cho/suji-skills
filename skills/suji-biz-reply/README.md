# suji-biz-reply

OpenDataLoader 비즈니스 문의에 대한 초기 답변 생성. Gmail 확인부터 초안 작성까지.

**scope: work only**

## When to use

- "비즈니스 문의 답변해야 해", "BIZ contact 메일 확인", "신규 문의 회신"
- `/suji-biz-reply`

## 파이프라인 위치

```
Gmail (OSS/BIZ contact 라벨)
    ↓
/suji-biz-reply (문의 확인 → 기본 답변 초안)
    ↓
/suji-work-minute (데일리 노트에 "기본 답변 제공" 기록)
/suji-bm-sync (BM 플랜과 연계 가능한 리드 정보)
```

## 커맨드

| 커맨드 | 용도 |
|--------|------|
| `/suji-biz-reply` | Gmail 열기 + 미회신 문의 확인 + 답변 초안 생성 |
| `/suji-biz-reply draft` | 문의 내용 직접 붙여넣기로 초안 생성 (브라우저 없이) |

## 워크플로우 요약

1. **Gmail 확인** — `/browse` 스킬로 브라우저 handoff → OSS/BIZ contact 라벨 이동 → 미회신 메일 확인
2. **문의 파악** — 이름, 소속, 문의 내용 추출 → 유형 분류 (기능/가격/PoC/협업/일반)
3. **답변 초안** — 기본 질문 5가지 + 유형별 추가 질문 포함한 영문 초안 생성
4. **확인 + 발송** — 사용자 수정 → 최종 출력 → 복사하여 발송
5. **팀장 보고** — 요청 시 회신 현황 요약 생성

## 기본 질문 5가지

1. PDF 처리량 (월/일 기준)
2. 문서 구조 (폼, 보고서, 레터 등)
3. 스캔/이미지 vs 디지털 네이티브 비중
4. 배포 형태 (클라우드/온프레미스/하이브리드)
5. 도입 목표 일정

## 문의 유형별 추가 안내

| 유형 | 추가 내용 |
