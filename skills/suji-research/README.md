# suji-research

리서치 수행부터 Confluence 업로드까지의 품질 기준과 파일 관리를 담당하는 스킬.

## 사용법

```
/suji-research    리서치 수행 또는 업로드
```

"리서치해줘", "조사해줘", "리서치 올려줘", "드래프트 올려줘" 등으로도 트리거된다.

## 출처 우선순위

리서치 결과물의 신뢰도는 출처가 결정한다.

1. 학술 기관 공식 발행물 (MIT, Stanford, CMU)
2. 표준 단체 공식 스펙 (W3C, IETF, ISO)
3. 기술 기업 공식 문서 (공식 블로그, 엔지니어링 블로그)
4. 피어리뷰 논문 (arXiv, ACM, IEEE)
5. 정부/국제기구 보고서

개인 블로그, 비공식 소스는 1차 출처로 사용 불가. 보조 참고만 가능.

## 문서 구조

모든 리서치 파일은 아래 구조를 따른다:

```
TL;DR → 배경 → 조사 내용 → 비교/분석 → 결론 & 제안 → 출처
```

필수 요소:
- TL;DR에 핵심 결과 + 구체적 수치
- 모든 주장에 번호 매긴 출처 매핑
- 2개 이상 대안 비교 시 테이블 필수
- 수치 미확보 시 `[확인 필요]` 표기

## 파일 경로

| 용도 | 경로 | 파일명 |
|------|------|--------|
| 리서치 | `~/Workspace/work/outputs/research/` | `yyyymmdd_filename.md` |
| 산출물 초안 | `~/Workspace/work/outputs/drafts/` | `yyyymmdd_제목.md` |

## Confluence 업로드

- 리서치 → OSS1 > PO/PM 파트 > 리서치 (Page ID: 1902903831)
- 드래프트 → 문서별 지정 (업로드 시 사용자에게 확인)

업로드 전 Ralph Loop 체크리스트 6항목을 전부 통과해야 한다.
