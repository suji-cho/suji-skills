## 개요

옵시디언에 작성한 회의록 원본 메모를 읽고, 결론 추출 + AI 정리를 수행한 뒤 Confluence에 업로드한다.

- 개인 회의록: `~/Workspace/obsidian/personal/`

- 파일명 규칙: `yyyy.mm.dd_제목.md`
- 태그: 문서 첫 줄에 해시태그 (`#연구소`, `#컨콜`, `#팀`, `#기타`, `#개인`)

## 워크플로우

### Step 1. 대상 파일 확인

사용자가 파일을 지정하거나, 가장 최근 수정된 옵시디언 파일을 대상으로 한다.
- `## 원본 메모` 섹션이 있는 파일만 대상
- 이미 `## 결론` 섹션이 있으면 "이미 정리된 파일입니다. 다시 정리할까요?" 확인

### Step 2. 결론 추출

원본 메모에서 아래 3가지를 추출한다.

**결정**: 회의에서 확정된 사항
**액션**: 누가 뭘 해야 하는지 (`- [ ]` 체크박스 + `@담당자`)
**공유 사항**: 알아야 하지만 결정은 아닌 정보

### Step 3. AI 정리

원본 메모를 읽기 쉽게 구조화한다.
- 중복 제거, 문맥 보완
- 불릿 계층 정리
- 원본의 의미를 변경하지 않음

### Step 4. 파일 업데이트

옵시디언 파일을 아래 구조로 업데이트한다.

```markdown
#연구소 #태그2

## 결론
### 결정
- (확정 사항)

### 액션
- [ ] 액션 아이템 @담당자

### 공유 사항
- (공유 정보)

---

## AI 정리
(구조화된 내용)

---

## 원본 메모
(기존 날것 메모 그대로 보존)
```

**사용자에게 결과를 보여주고 승인받은 뒤 파일에 반영한다.**

### Step 5. TODO 수집

`## 결론 > ### 액션`의 `- [ ]` 항목을 옵시디언 TODO 파일에 추가한다.

- 경로: `~/Workspace/obsidian/0_TODO/`
- 파일명: `2026_Apr_1 TODO.md` (월_주차별)
- 형식:

```markdown
## From yyyy.mm.dd_제목
- [ ] 액션 아이템 @담당자
```

- 해당 주차 파일이 없으면 새로 생성
- 이미 같은 항목이 있으면 중복 추가하지 않음

### Step 6. Confluence 업로드

`#개인` 태그가 아닌 경우 Confluence에 페이지를 생성한다.

- 첫 줄 해시태그로 폴더 결정
- 페이지 제목 = 옵시디언 파일명 (확장자 제외)
- contentFormat: markdown
- 같은 제목의 페이지가 있으면 업데이트

## 주의사항

- 원본 메모는 절대 수정하지 않음 (## 원본 메모 섹션 보존)
- AI 정리 및 결론은 사용자 승인 후 반영
- 디자인·콘텐츠 사용자 확인 없이 변경 불가
- `#개인` 태그 파일은 Confluence 업로드 제외
